# Getting Started

Welcome to the **Yupitek Wiki** — the technical support and documentation hub for the products we sell.

This wiki covers five product families:

| Brand | Focus | Product Family Page |
|-------|-------|---------------------|
| **ALFA Network** | Wi-Fi USB adapters, antennas, Linux/Kali support | [ALFA Network](/alfa-network/) |
| **Hak5** | Pentesting tools (WiFi Pineapple, Rubber Ducky, O.MG) | [Hak5](/hak5/) |
| **Flipper Zero** | Multi-tool device and accessories | [Flipper Zero](/flipper-zero/) |
| **SDRLAB** | Software-defined radio hardware | [SDRLAB](/sdrlab/) |
| **ACS** | Smart card readers and NFC | [ACS](/acs/) |

## How this wiki is organized

- Each brand has a dedicated section with its own product pages.
- Driver and firmware guides are grouped per chipset inside each brand.
- For complete lists of hardware models and chipset drivers, explore the dedicated product catalogs and driver directories in each brand section.

Pick a brand below to get started, or use the search bar in the top navigation.
