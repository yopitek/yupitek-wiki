# Product Registry

The Product Registry is the **single source of truth** for every product documented in the Yupitek Wiki. Each row links to the product's main page and records its category so the listing stays consistent across all locales.

Products are listed in the same order as the [Getting Started](/getting-started/) index and grouped by brand.

## Category Definitions

- **Wi-Fi Adapter** — USB network adapter that connects to Wi-Fi networks.
- **Antenna** — External antenna accessory to improve range or gain.
- **Device** — Standalone hardware product with embedded firmware.
- **Board** — Expansion board / devboard that pairs with a host device.
- **Module** — Add-on module that expands the capability of a host device.
- **Accessory** — Protective or aesthetic add-on (e.g. a case).

## Adding or Updating

Any new product, or a change to an existing product's page, must update this registry and the corresponding brand index in the same commit so the two never drift.
