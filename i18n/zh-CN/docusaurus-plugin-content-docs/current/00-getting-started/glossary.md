# 词汇表

本维基中你会遇到的各种术语的通俗易懂的定义。品牌和型号名称始终保留英文。

| 术语 | 定义 |
|------|------------|
| **Adapter** | 插入计算机以提供无线连接的 USB Wi-Fi 网卡。 |
| **Access Point (AP)** | 让无线客户端连接到网络的设备。启用 AP 模式可将无线网卡变成热点。 |
| **Monitor mode** | 一种无需关联到网络即可捕获原始 802.11 帧的无线模式 — 是 Wi-Fi 审计的基础。 |
| **Packet injection** | 在空中发送自定义无线帧，用于攻击和测试。 |
| **Driver** | 让操作系统与硬件通信的内核软件。内核内置驱动程序已构建在 Linux 中；树外驱动程序需要单独安装。 |
| **DKMS** | 一个 Linux 框架，在内核更新时自动重新构建树外内核模块。 |
| **Firmware** | 存储在设备本身的底层软件。 |
| **Firmware update** | 替换设备上的固件以添加功能或修复错误。 |
| **Troubleshooting** | 诊断和解决问题的过程。 |
| **Compatibility matrix** | 显示哪些无线网卡与哪些操作系统、芯片组和驱动程序兼容的表格。 |
| **Getting started / Quick start** | 引导您完成首次设置的简短指南。 |
| **Antenna gain** | 衡量天线在某个方向上集中射频能量的程度（以 dBi 为单位）。 |
| **Sub-GHz** | 低于 1 GHz 的无线电频率（例如 433 MHz），Flipper Zero 使用。 |
| **Software-defined radio (SDR)** | 部分在软件中实现的无线电，让一台设备可以接收和发射多种频率。 |
| **NFC / RFID** | 非接触式卡技术（13.56 MHz NFC 和 125 kHz RFID），读卡器和 Flipper Zero 使用。 |
| **PC/SC** | 在计算机上访问智能卡读卡器的标准软件框架。 |

## 本维基中使用的约定

- **品牌和型号名称**（例如 `AWUS036ACM`、`WiFi Pineapple`）从不翻译。
- 英文技术术语首次出现时，会进行内联解释。
- 本维基中的路由路径使用 `/alfa-network/` 形式 — 完整列表请参阅 产品注册表。

如果某个术语缺失或定义不清楚，请向技术团队提出反馈。
