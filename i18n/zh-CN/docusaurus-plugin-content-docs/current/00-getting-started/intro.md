# 快速入门

欢迎来到 **Yupitek Wiki** — 我们销售产品的技术支持与文档中心。

本维基涵盖五个产品系列：

| 品牌 | 重点 | 产品系列页面 |
|-------|-------|---------------------|
| **ALFA Network** | Wi-Fi USB adapter（无线网卡）、天线、Linux/Kali 支持 | [ALFA Network](/alfa-network/) |
| **Hak5** | 渗透测试工具（WiFi Pineapple、Rubber Ducky、O.MG） | [Hak5](/hak5/) |
| **Flipper Zero** | 多功能工具设备和配件 | [Flipper Zero](/flipper-zero/) |
| **SDRLAB** | 软件无线电硬件 | [SDRLAB](/sdrlab/) |
| **ACS** | 智能卡读卡器和 NFC | [ACS](/acs/) |

## 本维基的组织方式

- 每个品牌都有独立的板块，包含自己的产品页面。
- driver（驱动程序）和 firmware（固件）指南按芯片组分组，位于各品牌板块内。
- 全局管理页面（产品注册表、驱动程序注册表、翻译词汇表）位于 Admin 板块。

在下方选择一个品牌开始，或使用顶部导航中的搜索栏。
