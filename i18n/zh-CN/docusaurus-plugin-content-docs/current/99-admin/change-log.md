# 变更日志

本日志记录 Yupitek Wiki 的重要变更。最新条目在最上方。

## 2026-08-21 — 阶段 1（英文源内容）

- 初始化 Docusaurus monorepo。
- 为全部 5 个品牌编写完整的**英文源**内容：
  - **ALFA Network** — 网卡适配器对比、Linux 兼容性矩阵、Ubuntu/Kali/NetHunter 设置指南、故障排查、7 份芯片组驱动指南、3 份硬件指南（Jetson / Raspberry Pi / Unitree）以及 14 个产品页面。
  - **HAK5** — 固件与下载、快速入门、FAQ、故障排查以及 17 个产品页面。
  - **Flipper Zero** — 快速入门、固件与 qFlipper、移动应用、官方资源、故障排查以及 4 个产品页面。
  - **SDRLAB** — SDR 软件、固件、快速入门、故障排查、3 个硬件页面、4 个 Flipper 扩展页面以及一份共享的 ALFA Linux 指南。
  - **ACS** — 索引页和 3 个智能卡读卡器产品页面。
- 新增**快速入门**页面：FAQ、支持政策与术语表。
- 新增**管理**页面：产品注册表、驱动注册表、翻译术语表、模板、审核队列以及本变更日志。
- 设置 3 个 Cloudflare Pages 部署工作流（`en` / `zh-cn` / `zh-tw`）。
