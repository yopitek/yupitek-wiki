# 翻译术语表

本术语表定义了 wiki 中使用的规范英文 / 简体中文（zh-CN）/ 繁体中文（zh-TW）术语。**英文源**是唯一事实来源；zh-CN 与 zh-TW 页面必须使用这些精确术语以保持一致。

## 术语表

| English | zh-CN (简中) | zh-TW (繁中) |
|---------|--------------|--------------|
| Access Point (AP) | 接入点 | 存取點 |
| Monitor mode | 监听模式 | 監聽模式 |
| Packet injection | 数据包注入 | 封包注入 |
| Adapter (wireless) | 网卡适配器 | 無線網卡 |
| Driver | 驱动程序 | 驅動程式 |
| Firmware | 固件 | 韌體 |

| Compatibility matrix | 兼容性矩阵 | 相容性矩陣 |
| Getting started | 快速入门 | 快速入門 |
| Wi-Fi adapter | 无线网卡 | Wi-Fi 無線網卡 |
| Antenna gain | 天线增益 | 天線增益 |

## 规则

- **品牌与型号名称绝不翻译。** 保持 `ALFA`、`AWUS036ACM`、`HAK5`、`Flipper Zero`、`SDRLAB`、`TRX-duo`、`ACR1252U` 等与英文完全一致。
- **技术术语在翻译页面中的首次出现**应保留英文术语并附括号说明，例如 `monitor mode（监听模式）`，之后复用翻译后的术语。
- 英文源页面具有权威性。如果此处缺少某个术语，请添加它并在同一次更改中更新全部三个语言版本。
