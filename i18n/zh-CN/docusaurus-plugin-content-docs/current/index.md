# Yupitek Wiki

欢迎来到 **Yupitek Wiki**，这是 [yupitek.com](https://www.yupitek.com) 上所有产品的技术支持与文档中心。

选择一个产品系列开始：

- [**ALFA Network**](/alfa-network/) — Wi-Fi adapter（无线网卡）、天线、Linux/Kali 驱动程序和硬件集成。
- [**Hak5**](/hak5/) — WiFi Pineapple、USB Rubber Ducky、Bash Bunny、O.MG 等。
- [**Flipper Zero**](/flipper-zero/) — 多功能工具设备、firmware（固件）和配件。
- [**SDRLAB**](/sdrlab/) — 软件无线电硬件和扩展模块。
- [**ACS**](/acs/) — 智能卡读卡器和 NFC 设备。

使用侧边栏或搜索栏进行导航。每个产品页面都包含规格、分步设置指南和 troubleshooting（故障排查）。
