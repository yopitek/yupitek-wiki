# 翻譯詞彙表

本詞彙表定義 wiki 各處使用的標準英文／簡體中文（zh-CN）／繁體中文（zh-TW）術語。**英文原文**是事實來源；zh-CN 與 zh-TW 頁面必須使用這些確切術語以保持一致。

## 術語表格

| English | zh-CN (简中) | zh-TW (繁中) |
|---------|--------------|--------------|
| Access Point (AP) | 接入点 | 存取點 |
| Monitor mode | 监听模式 | 監聽模式 |
| Packet injection | 数据包注入 | 封包注入 |
| Adapter (wireless) | 网卡适配器 | 無線網卡 |
| Driver | 驱动程序 | 驅動程式 |
| Firmware | 固件 | 韌體 |
| Firmware update | 固件升级 | 韌體更新 |

| Compatibility matrix | 兼容性矩阵 | 相容性矩陣 |
| Getting started | 快速入门 | 快速入門 |
| Wi-Fi adapter | 无线网卡 | Wi-Fi 無線網卡 |
| Antenna gain | 天线增益 | 天線增益 |

## 規則

- **品牌與型號名稱絕不翻譯。** 讓 `ALFA`、`AWUS036ACM`、`HAK5`、`Flipper Zero`、`SDRLAB`、`TRX-duo`、`ACR1252U` 等保持與英文完全一致。
- **技術術語在翻譯頁面中的首次出現**應保留英文術語並附括號說明，例如 `monitor mode（監聽模式）`，之後再沿用翻譯後的術語。
- 英文來源頁面具有權威性。如果這裡缺少某個術語，請新增它，並在同一次變更中更新全部三個語言版本。
