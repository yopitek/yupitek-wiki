## 類別定義

- **Wi-Fi 網卡** — 連接 Wi-Fi 網路的 USB 網路卡。
- **天線** — 用於改善範圍或增益的外部天線配件。
- **裝置** — 內建韌體的獨立硬體產品。
- **擴充板** — 與主機裝置搭配使用的擴充板／開發板。
- **模組** — 擴充主機裝置能力的附加模組。
- **配件** — 保護性或美觀性的附加配件（例如外殼）。

## 新增或更新

任何新產品，或既有產品頁面的變更，都必須在同一個 commit 中更新本登記表與對應的品牌索引，讓兩者永遠不會脫節。
